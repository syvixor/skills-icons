# Skills Icons への貢献

Skills Icons への貢献にご興味をお持ちいただきありがとうございます。皆様の時間と努力に感謝します。貢献することで、プロジェクトをより良くしていくことに役立ちます。

貢献を行う前に、以下のガイドラインをよく読んで、プロジェクトの目的や基準に沿った内容にしてください。

## 貢献方法

### 1. バグの報告

バグや問題を見つけた場合は、次の手順に従ってください。

- 既存の issue を検索し、すでに報告されていないか確認する
- 未報告であれば、新しい issue を作成する

### 2. アイコンの提供

#### アイコンテンプレート

- [Normal Icon](../../.github/ICON_TEMPLATES/icon.svg)
- [Themed Icon](../../.github/ICON_TEMPLATES/themed_icon.svg)

新しいアイコンを提案したい場合は、次の手順に従ってください。

- 提供されているアイコンテンプレートをダウンロードして使用してください。これらのテンプレートは、プロジェクト全体でアイコンのスタイルを統一するために設計されています。

- アイコンがプロジェクトの元のデザイン原則に沿っていることを確認してください。

- **サイズ**、**スタイル**、**明瞭さ**に注意してください。

- アイコンは /icons ディレクトリに配置してください。アイコンファイル名が命名規則と一致していることを確認してください（例: iconname.svg）。

### 3. プルリクエストのレビュー手順

プルリクエストを送信した後、メンテナーがレビューを行い、説明や修正の依頼をする場合があります。フィードバックや変更依頼には迅速に対応してください。

## 行動規範

本プロジェクトに貢献することで、敬意と包括性を重視したコミュニケーションを行うための[行動規範](../../.github/CODE_OF_CONDUCT.md) に同意したものとみなされます。

## ライセンス

本プロジェクトに貢献することで、あなたの貢献が[プロジェクトのライセンス](../../LICENSE) の下で公開されることに同意したものとみなされます。
