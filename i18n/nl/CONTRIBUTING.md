# Bijdragen aan Skills Icons

Bedankt voor je interesse in het bijdragen aan Skills Icons! We waarderen je tijd en inzet. Door bij te dragen help je dit project te verbeteren voor iedereen.

Lees de volgende richtlijnen door om ervoor te zorgen dat je bijdragen aansluiten bij de doelen en standaarden van het project.

## Hoe bij te dragen

### 1. Bugs melden

Als je een bug of probleem vindt, volg dan deze stappen:

- Controleer of er al een bestaand issue is om te zien of de bug al gemeld is.
- Als de bug nog niet gemeld is, open dan een nieuw issue.

### 2. Een icoon bijdragen

#### Icoonsjablonen

- [Normaal icoon](https://github.com/syvixor/skills-icons/blob/main/.github/ICON_TEMPLATES/icon.svg)
- [Thema-icoon](https://github.com/syvixor/skills-icons/blob/main/.github/ICON_TEMPLATES/themed_icon.svg)

Als je een nieuw icoon wilt bijdragen, volg dan deze stappen:

- Download de meegeleverde icoonsjablonen en gebruik ze. Deze sjablonen zijn ontworpen om uniformiteit in icoonstijl door het project te waarborgen.

- Zorg ervoor dat je icoon voldoet aan de oorspronkelijke ontwerpprincipes van het project.

- Let op **afmetingen**, **stijl** en **duidelijkheid**.

- Iconen moeten in de map `/icons` geplaatst worden. Zorg ervoor dat het icoonbestand consistent benoemd is volgens de naamgevingsconventie (bijv. icoonnaam.svg).

### 3. Beoordelingsproces voor pull requests

Zodra je een pull request indient, zullen de beheerders het beoordelen en kunnen zij om verduidelijkingen of wijzigingen vragen. Reageer alsjeblieft op eventuele feedback of verzoeken om wijzigingen.
