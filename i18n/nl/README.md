| --------- | --------------------------------------------------- | --------- | --------- |
| `i`       | Door komma's gescheiden lijst van icoonnamen        | Ja        | /         |
| `perline` | Aantal iconen per regel                             | Nee       | 15        |
| `radius`  | Hoekradius van icoon(en) (waarde tussen 25 en 85)   | Nee       | 40        |

### Donker en licht thema 🌗

`Skills Icons` ondersteunt nu automatische themadetectie — iconen passen zich naadloos aan het donkere 🌙 of lichte ☀️ thema van je systeem aan zonder parameters of handmatige instelling.

Dit gedrag wordt mogelijk gemaakt door de ingebouwde `CSS`-mediaquery `prefers-color-scheme`, die de huidige themavoorkeur van de gebruiker detecteert en de SVG-kleuren dienovereenkomstig aanpast.

### Docker-gebruik 🐳

Deze sectie biedt instructies voor het bouwen en uitvoeren van het `Skills Icons` project met Docker. Volg de onderstaande stappen om de applicatie efficiënt te containeriseren en te beheren.

#### Vereisten

Zorg ervoor dat het volgende geïnstalleerd is voordat je begint:

- Docker (versie 18.09 of hoger)

#### De Docker-image bouwen

Volg deze stappen om de Docker-image voor `Skills Icons` te bouwen:

1. Open een terminal en navigeer naar de map.
2. Voer het volgende commando uit om de image te bouwen:

```bash
docker build -t skills-icons .
# of
sudo docker build -t skills-icons .
```

#### De Docker-container uitvoeren

Zodra de image gebouwd is, kun je deze in een container uitvoeren:

1. Voer het volgende commando uit:

```bash
docker run -p 3000:3000 skills-icons
# of
sudo docker run -p 3000:3000 skills-icons
```

Dit commando koppelt poort 3000 van je hostmachine aan poort 3000 van de container, waardoor je `Skills Icons` kunt bereiken via http://localhost:3000.
