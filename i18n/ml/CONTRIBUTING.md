# Skills Icons-ലേക്കുള്ള സംഭാവന

Skills Icons-ലേക്ക് സംഭാവന ചെയ്യാൻ താൽപ്പര്യം കാണിച്ചതിന് നന്ദി! നിങ്ങളുടെ സമയത്തെയും പരിശ്രമത്തെയും ഞങ്ങൾ വിലമതിക്കുന്നു. സംഭാവന ചെയ്യുന്നതിലൂടെ, ഈ പ്രോജക്റ്റ് എല്ലാവർക്കും കൂടുതൽ മെച്ചപ്പെടുത്താൻ നിങ്ങൾ സഹായിക്കുകയാണ്.

നിങ്ങളുടെ സംഭാവനകൾ പ്രോജക്റ്റിന്റെ ലക്ഷ്യങ്ങളോടും നിലവാരങ്ങളോടും പൊരുത്തപ്പെടുന്നുവെന്ന് ഉറപ്പാക്കാൻ ദയവായി താഴെയുള്ള മാർഗ്ഗനിർദ്ദേശങ്ങൾ വായിക്കുക.

## എങ്ങനെ സംഭാവന ചെയ്യാം

### 1. ബഗുകൾ റിപ്പോർട്ട് ചെയ്യൽ

ഒരു ബഗോ പ്രശ്നമോ കണ്ടാൽ, ദയവായി ഈ ഘട്ടങ്ങൾ പാലിക്കുക:

- ബഗ് ഇതിനകം റിപ്പോർട്ട് ചെയ്തിട്ടുണ്ടോ എന്നറിയാൻ നിലവിലുള്ള ഒരു issue ഉണ്ടോ എന്ന് തിരയുക.
- ബഗ് ഇതുവരെ റിപ്പോർട്ട് ചെയ്തിട്ടില്ലെങ്കിൽ, ഒരു പുതിയ issue തുറക്കുക

### 2. ഐക്കൺ സംഭാവന

#### ഐക്കൺ ടെംപ്ലേറ്റുകൾ

- [സാധാരണ ഐക്കൺ](https://github.com/syvixor/skills-icons/blob/main/.github/ICON_TEMPLATES/icon.svg)
- [തീം ഐക്കൺ](https://github.com/syvixor/skills-icons/blob/main/.github/ICON_TEMPLATES/themed_icon.svg)

ഒരു പുതിയ ഐക്കൺ സംഭാവന ചെയ്യാൻ ആഗ്രഹിക്കുന്നുവെങ്കിൽ, ദയവായി ഈ ഘട്ടങ്ങൾ പാലിക്കുക:

- നൽകിയിട്ടുള്ള ഐക്കൺ ടെംപ്ലേറ്റുകൾ ഡൗൺലോഡ് ചെയ്ത് ഉപയോഗിക്കുക. പ്രോജക്റ്റിലുടനീളം ഐക്കൺ ശൈലിയിൽ ഏകരൂപത ഉറപ്പാക്കാനാണ് ഈ ടെംപ്ലേറ്റുകൾ രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്.

- നിങ്ങളുടെ ഐക്കൺ പ്രോജക്റ്റിന്റെ യഥാർത്ഥ രൂപകൽപ്പനാ തത്വങ്ങൾ പാലിക്കുന്നുവെന്ന് ഉറപ്പാക്കുക.

- **വലുപ്പം**, **ശൈലി**, **വ്യക്തത** എന്നിവയിൽ ശ്രദ്ധ ചെലുത്തുക.

- ഐക്കണുകൾ /icons ഡയറക്ടറിയിൽ സ്ഥാപിക്കണം. ഐക്കൺ ഫയലിന്റെ പേര് നാമകരണ രീതിക്ക് അനുസൃതമാണെന്ന് ഉറപ്പാക്കുക (ഉദാ: iconname.svg).

### 3. Pull Request അവലോകന പ്രക്രിയ

ഒരു pull request സമർപ്പിച്ചുകഴിഞ്ഞാൽ, മെയിന്റൈനർമാർ അത് അവലോകനം ചെയ്യുകയും വ്യക്തതയോ മാറ്റങ്ങളോ ആവശ്യപ്പെടുകയും ചെയ്തേക്കാം. ഫീഡ്‌ബാക്കിനോടും മാറ്റങ്ങൾക്കായുള്ള അഭ്യർത്ഥനകളോടും ദയവായി വേഗത്തിൽ പ്രതികരിക്കുക.

## പെരുമാറ്റച്ചട്ടം

ഈ പ്രോജക്റ്റിലേക്ക് സംഭാവന ചെയ്യുന്നതിലൂടെ, ആദരവും ഉൾക്കൊള്ളലും നിറഞ്ഞ ആശയവിനിമയത്തിനുള്ള പ്രതീക്ഷകൾ നിശ്ചയിക്കുന്ന ഞങ്ങളുടെ [പെരുമാറ്റച്ചട്ടം](https://github.com/syvixor/skills-icons/blob/main/.github/CODE_OF_CONDUCT.md) പിന്തുടരാൻ നിങ്ങൾ സമ്മതിക്കുന്നു.
