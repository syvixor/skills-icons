### ഡാർക്ക്‌ & ലൈറ്റ് മോഡ് 🌗

`Skills Icons` ഇപ്പോൾ **ഓട്ടോമാറ്റിക് തീം ഡിറ്റക്ഷൻ** പിന്തുണയ്ക്കുന്നു —
നിങ്ങളുടെ സിസ്റ്റം **ഡാർക്ക് 🌙** അല്ലെങ്കിൽ **ലൈറ്റ് ☀️** മോഡിലാണോ എന്നതനുസരിച്ച് ഐക്കണുകൾ സ്വയമേ മാറ്റം വരുത്തും.

ഇതിന് യാതൊരു അധിക പാരാമീറ്ററുകളോ മാനുവൽ സെറ്റപ്പുകളോ ആവശ്യമില്ല.

ഈ സൗകര്യം `CSS`-യിലെ `prefers-color-scheme` എന്ന ബിൽറ്റ്-ഇൻ മീഡിയ ക്വറി ഉപയോഗിച്ചാണ് പ്രവർത്തിക്കുന്നത്.
ഇത് ഉപയോക്താവിന്റെ നിലവിലെ തീം പ്രിഫറൻസ് തിരിച്ചറിഞ്ഞ് SVG നിറങ്ങൾ അതനുസരിച്ച് ക്രമീകരിക്കുന്നു.

* **ഡോക്യുമെന്റേഷൻ**: രേഖകൾ മെച്ചപ്പെടുത്താൻ സഹായിക്കുക

### Docker ഉപയോഗം 🐳

Docker ഉപയോഗിച്ച് `Skills Icons` പ്രോജക്റ്റ് നിർമ്മിക്കുകയും പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നതിനുള്ള മാർഗനിർദ്ദേശങ്ങളാണ് ഈ വിഭാഗത്തിൽ നൽകിയിരിക്കുന്നത്.

#### Prerequisites

തുടങ്ങുന്നതിന് മുൻപ് താഴെ പറയുന്നവ ഇൻസ്റ്റാൾ ചെയ്തിരിക്കണം:

* Docker (version 18.09 അല്ലെങ്കിൽ അതിൽ കൂടുതലുള്ളത്)

#### Building the Docker Image

Docker ഇമേജ് നിർമ്മിക്കാൻ:

1. ടെർമിനൽ തുറന്ന് പ്രോജക്റ്റ് ഡയറക്ടറിയിലേക്ക് പോവുക
2. താഴെ കൊടുത്തിരിക്കുന്ന കമാൻഡ് പ്രവർത്തിപ്പിക്കുക

```bash
docker build -t skills-icons .
# അല്ലെങ്കിൽ
sudo docker build -t skills-icons .
```

#### Running the Docker Container

ഇമേജ് നിർമ്മിച്ചതിന് ശേഷം, കണ്ടെയ്‌നർ പ്രവർത്തിപ്പിക്കാൻ:

```bash
docker run -p 3000:3000 skills-icons
# അല്ലെങ്കിൽ
sudo docker run -p 3000:3000 skills-icons
```

ഈ കമാൻഡ് നിങ്ങളുടെ ഹോസ്റ്റ് മെഷീനിലെ പോർട്ട് `3000`
കണ്ടെയ്‌നറിലെ പോർട്ട് `3000`-ലേക്ക് മാപ്പ് ചെയ്യും.

അതുവഴി `Skills Icons`
👉 [http://localhost:3000](http://localhost:3000)
എന്ന വിലാസത്തിൽ ആക്‌സസ് ചെയ്യാം.

### Icon നീക്കം ചെയ്യാൻ 🚫

ഞങ്ങൾ എല്ലാ ബ്രാൻഡിംഗ് മാർഗനിർദ്ദേശങ്ങളും ബൗദ്ധിക സ്വത്തവകാശങ്ങളും ആദരിക്കാൻ ശ്രമിക്കുന്നു.

നിങ്ങൾ:

* ഒരു കമ്പനി പ്രതിനിധീകരിക്കുന്നയാളാണെങ്കിൽ
* ആ കമ്പനിയുടെ ഐക്കൺ ഈ പ്രോജക്റ്റിൽ ഉൾപ്പെടുത്തിയിട്ടുണ്ടെങ്കിൽ
* അല്ലെങ്കിൽ ബ്രാൻഡിംഗ് മാർഗനിർദ്ദേശങ്ങൾ ലംഘിച്ചാണ് ഐക്കൺ ഉപയോഗിച്ചതെന്ന് നിങ്ങൾ വിശ്വസിക്കുന്നുവെങ്കിൽ

ദയവായി ഈ റെപ്പോസിറ്ററിയിൽ ഒരു **Issue** തുറന്ന് നിങ്ങളുടെ അഭ്യർത്ഥന വിശദീകരിക്കുക.
ഞങ്ങൾ അത് ഉടൻ പരിശോധിച്ച് ആവശ്യമായ നടപടി സ്വീകരിക്കും.
നിങ്ങളുടെ സഹകരണത്തിന് നന്ദി.
