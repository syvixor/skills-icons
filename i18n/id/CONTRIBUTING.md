# Berkontribusi pada Skills Icons

Terima kasih atas minat Anda untuk berkontribusi pada Skills Icons! Kami menghargai waktu dan upaya Anda. Dengan berkontribusi, Anda membantu meningkatkan proyek ini untuk semua orang.

Harap baca panduan berikut untuk memastikan bahwa kontribusi Anda selaras dengan tujuan dan standar proyek.

## Cara Berkontribusi

### 1. Melaporkan Bug

Jika Anda menemukan bug atau masalah, silakan ikuti langkah-langkah berikut:

- Cari apakah ada issue yang sudah ada untuk melihat apakah bug tersebut telah dilaporkan.
- Jika bug belum dilaporkan, buka issue baru.

### 2. Kontribusi Ikon

#### Templat Ikon

- [Ikon Normal](ICON_TEMPLATES/icon.svg)
- [Ikon Bertema](ICON_TEMPLATES/themed_icon.svg)

Jika Anda ingin berkontribusi ikon baru, silakan ikuti langkah-langkah berikut:

- Unduh dan gunakan templat ikon yang disediakan. Templat ini dirancang untuk memastikan keseragaman gaya ikon di seluruh proyek.

- Pastikan ikon Anda mematuhi prinsip desain asli dari proyek ini.

- Perhatikan sizing, style, dan clarity.

- Ikon harus ditempatkan di direktori /icons. Pastikan file ikon diberi nama secara konsisten sesuai dengan konvensi penamaan (misalnya, namaikon.svg).

### 3. Proses Tinjauan Pull Request

Setelah Anda mengajukan pull request, pengelola akan meninjaunya dan mungkin meminta klarifikasi atau perubahan. Harap responsif terhadap umpan balik atau permintaan perubahan apa pun.

## Kode Etik

Dengan berkontribusi pada proyek ini, Anda setuju untuk mengikuti [Kode Etik](CODE_OF_CONDUCT.md) kami, yang menetapkan ekspektasi untuk komunikasi yang saling menghormati dan inklusif.

## Lisensi

Dengan berkontribusi pada proyek ini, Anda setuju bahwa kontribusi Anda akan dilisensikan di bawah [lisensi proyek](../LICENSE).
