### Pilihan Konfigurasi 🛠️

| Parameter | Huraian                                     | Diperlukan | Lalai |
| --------- | ----------------------------------------------- | -------- | ------- |
| `i`       | Senarai nama ikon yang dipisahkan dengan koma   | Yes      | /       |
| `perline` | Bilangan ikon setiap baris                      | No       | 15      |
| `radius`  | Jejari sudut ikon (nilai antara 25 dan 85)      | No       | 40      |

### Mod Cerah & Gelap 🌗

`Skills Icons` kini menyokong pengesanan tema secara automatik — ikon akan menyesuaikan diri dengan lancar mengikut mod gelap 🌙 atau cerah ☀️ sistem anda tanpa sebarang parameter atau tetapan manual.

Gelagat ini dikuasakan oleh *media query* terbina dalam `CSS` iaitu `prefers-color-scheme`, yang mengesan pilihan tema semasa pengguna dan melaraskan warna SVG sewajarnya.

### Penggunaan Docker 🐳

Bahagian ini menyediakan arahan untuk membina dan menjalankan projek `Skills Icons` menggunakan Docker. Ikuti langkah-langkah di bawah untuk melakukan kontenaan dan mengurus aplikasi tersebut dengan cekap.

#### Prasyarat

Sebelum anda bermula, pastikan anda telah memasang perkara berikut:

- Docker (versi 18.09 atau lebih tinggi)

#### Membina Imej Docker

Untuk membina imej Docker bagi `Skills Icons`, ikuti langkah-langkah berikut:

1. Buka terminal dan navigasi ke direktori tersebut.
2. Jalankan arahan berikut untuk membina imej:

```bash
docker build -t skills-icons .
# or
sudo docker build -t skills-icons .
```

#### Menjalankan Docker Container

Setelah imej dibina, anda boleh menjalankannya di dalam bekas (container):

1. Jalankan arahan berikut:

```bash
docker run -p 3000:3000 skills-icons
# or
sudo docker run -p 3000:3000 skills-icons
```

Arahan ini memetakan port 3000 mesin hos anda kepada port 3000 bekas (container), membolehkan anda mengakses `Skills Icons` di http://localhost:3000.
