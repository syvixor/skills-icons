### Використання Docker 🐳

У цьому розділі описано, як зібрати та запустити проєкт `Skills Icons` за допомогою Docker. Виконайте наведені нижче кроки, щоб контейнеризувати застосунок і керувати ним.

#### Вимоги

Переконайтеся, що у вас встановлено таке програмне забезпечення:
- Docker (версії 18.09 або новішої)

#### Збірка Docker-образу

Щоб зібрати Docker-образ для `Skills Icons`:
1. Відкрийте термінал і перейдіть до каталогу проєкту
2. Виконайте таку команду:
```bash
docker build -t skills-icons .
# або
sudo docker build -t skills-icons .
```

#### Запуск Docker-контейнера

Після збірки образу його можна запустити в контейнері:
1. Виконайте таку команду:
```bash
docker run -p 3000:3000 skills-icons
# або
sudo docker run -p 3000:3000 skills-icons
```

Ця команда запустить контейнер і зробить його доступним через порт 3000, після чого застосунок `Skills Icons` буде доступний у вашому браузері за адресою http://localhost:3000.
