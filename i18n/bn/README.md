## ডার্ক এবং লাইট মোড সাপোর্ট 🌗

`Skills Icons` এখন স্বয়ংক্রিয় থিম সনাক্তকরণ সাপোর্ট করে — আইকনগুলো আপনার সিস্টেমের ডার্ক 🌙 বা লাইট ☀️ মোড অনুযায়ী নিজে থেকেই অ্যাডজাস্ট হয়ে যায়।

এই সুবিধাটি `CSS`-এর বিল্ট-ইন মিডিয়া কোয়েরি `prefers-color-scheme` ব্যবহার করে, যা ব্যবহারকারীর থিম পছন্দ সনাক্ত করে SVG-র রঙ পরিবর্তন করে দেয়।

- **ডকুমেন্টেশন**: ডকুমেন্টেশনের মান উন্নত করতে সাহায্য করুন।

# 🐳 Docker ব্যবহার

এই সেকশনে দেখানো হয়েছে কীভাবে Docker-এর সাহায্যে `Skills Icons` নির্মাণ এবং রান করবেন।

## পূর্বশর্ত

সামনে এগোনোর আগে এগুলি ইনস্টল করা থাকতে হবে:

- Docker (ভার্সান 18.09 বা তার উপরে)

## Docker Image তৈরি করা

`Skills Icons`-এর Docker ইমেজ তৈরি করতে:

1. টার্মিনাল খুলুন এবং প্রজেক্ট ডিরেক্টরিতে যান।
2. নিচে দেয়া কমান্ডটি রান করুন:

```bash
docker build -t skills-icons .
# বা
sudo docker build -t skills-icons .
```

## Docker Container চালানো

ইমেজ তৈরি হয়ে গেলে কন্টেনার রান করার জন্য:

```bash
docker run -p 3000:3000 skills-icons
# বা
sudo docker run -p 3000:3000 skills-icons
```

এই কমান্ডটি আপনার সিস্টেমের port 3000-কে কন্টেইনারের port 3000-এর সাথে ম্যাপ করে, যার ফলে আপনি [http://localhost:3000](http://localhost:3000)-এ অ্যাপটি অ্যাক্সেস করতে পারবেন।
